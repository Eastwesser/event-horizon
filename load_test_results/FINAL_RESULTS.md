## Узкие места

1. TCP connection limit на одном сервере
2. NATS slow consumer при >6000 сообщений/сек
3. PostgreSQL pool ограничен 100 соединениями
4. Файловые дескрипторы (ulimit -n)

## Скейлинг

Для 100k пользователей необходимо:
- 5-10 экземпляров Gateway
- 5-10 экземпляров Game
- 3-5 NATS нод
- Redis Cluster
- PostgreSQL Cluster
- Балансировщик нагрузки (nginx/haproxy)
