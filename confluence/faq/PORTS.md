# 📡 EventHorizon: Справочник по портам

Дата: 16 июня 2026
Назначение: Быстрая шпаргалка по всем сетевым портам, используемым в проекте.

# 1. Базы данных (PostgreSQL)

Сервис	    Внутренний порт	Хост-порт	Назначение
Auth	    5432	        5460	    Хранение пользователей, хэшей паролей
Game	    5432	        5461	    История игр и рекордов
Billing	    5432	        5462	    Транзакции и балансы (лампочки/билетики)
Leaderboard	5432	        5463	    Бэкап данных для топа (дублирование из Redis)

# 2. Кэш и очереди (Redis)

Сервис	    Внутренний порт	Хост-порт	Назначение
Auth	    6379	        6379	    JWT Refresh-токены, временные сессии
Game	    6379	        380	        Кэш игровых состояний (анти-читерство)
Billing	    6379	        6381	    Кэш текущих балансов
Leaderboard	6379	        6382	    Sorted Set для хранения топа игроков

# 3. gRPC (Внутренние сервисы)

Сервис	    Порт	Протокол	Назначение
Auth	    50051	gRPC	    Проверка JWT, логин/регистрация
Game	    50052	gRPC	    Валидация ходов, подсчет очков
Billing	    50053	gRPC	    Начисление валюты после игры
Leaderboard	50054	gRPC	    Получение топа и обновление рекордов

# 4. API Gateway (Входная точка)

Компонент	Порт	Протокол	        Назначение
Gateway	    8080	HTTP / WebSocket	REST API для фронтенда и WS для лидерборда

# 5. Брокер сообщений (NATS)

Компонент	    Порт	Протокол	Назначение
NATS Client	    4222	TCP	        Публикация и подписка на события (score.updated)
NATS Monitoring	8222	HTTP	    Просмотр статистики очередей (JetStream)

6. Мониторинг (Планируется к внедрению)

Компонент	Порт	Протокол	Назначение
Prometheus	9090	HTTP	    Сбор метрик с сервисов
Grafana	    3000	HTTP	    Визуализация дашбордов

# 7. Быстрые команды для проверки

```bash
# Проверить, какие порты сейчас слушаются
sudo ss -tlnp | grep -E "5460|5461|5462|5463|6379|6380|6381|6382|50051|50052|50053|50054|8080|4222|8222"

# Проверить доступность конкретного порта (например, Gateway)
curl http://localhost:8080/health

# Посмотреть логи NATS (если что-то не так с брокером)
nats sub ">" --server localhost:4222
```
