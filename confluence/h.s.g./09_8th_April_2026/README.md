## Задачи

### 1. `InvertMap`
`map[string]int` → `map[int][]string`. Значения исходной map могут совпадать — ключи с одним value кладём в слайс. На собесе: «ключ и value меняем местами; при коллизии `append` в `[]string`; порядок внутри слайса не гарантирован (как `range` по map)».

### 2. `UnionAllInts`
Variadic `...[]int`: объединить, убрать дубли, сохранить порядок первого появления. Краевые: `nil`-слайсы, пустой вызов → `[]int{}`. Фраза: «set на `map[int]struct{}` + один проход».

### 3. `compactString` (RLE)
`"hhhhgggrreeee"` → `"h4g3r2e4"`. Счётчик серии, `strings.Builder` / `fmt.Sprintf("%c%d", …)`. Не потеряй последнюю группу. На собесе уточни: если count=1 — писать ли `a1` или `a` (здесь — всегда с числом, как в конспекте).

### 4. `Group` (аналог WaitGroup на канале)
Буферизованный `chan struct{}` размера N: `Done` кладёт токен, `Wait` забирает N. Без `Add` — размер известен заранее. Фраза: «семафор наоборот: ждём N сигналов».
