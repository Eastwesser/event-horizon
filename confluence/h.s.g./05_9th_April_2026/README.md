# Урок 05 — 9 апреля 2026

Теория для легенды: Strangler Fig (монолит→микросервисы), CI/CD canary, профилирование/TCO, уровни SD, метрики. Код — демо маршрутизации трафика.

## Задачи / что говорить

### 1. Strangler Fig
Новый сервис рядом со старым; % трафика растёт 5→20→50→100; смотрим error rate/latency; dual-write или Kafka sync. Не «переписали монолит за ночь».

### 2. Canary deploy
После merge → stage → prod canary; rollback < 1 мин. Демо: роутер по проценту.

### 3. Техдолг через деньги
TCO: «2 недели разработки vs $2000/мес серверов». Профилируем по SLA/инциденту, не «для красоты».
