## Задачи

### 1. `uniqRandn` — уникальные случайные числа
Слайд длины `n` без дубликатов. На собесе говори: set (`map[T]struct{}`) + цикл пока `len(set) < n`; сложность по времени зависит от диапазона `IntN`. Краевые: `n <= 0` → пустой слайс; если `n` больше диапазона — бесконечный цикл (упомяни ограничение).

### 2. `isMonotonic` — монотонный слайс
Два флага `inc`/`dec`: при нарушении неубывания/невозрастания сбрасываем. Итог `inc || dec`. Скажи O(n)/O(1) и что равные элементы допустимы (`{1,1}` → true).

### 3. Чемпионат по шагам
Суммируем шаги и дни участия; чемпионы — те, у кого `daysPresent == totalDays` и max сумма. Проговаривай: «сначала агрегация, потом фильтр без пропусков, потом сбор ничьих».

### 4. Outbox (теория + демо)
Junior: `go func` → Middle: брокер → Senior: outbox в одной транзакции с заказом + poller `FOR UPDATE SKIP LOCKED`. Демо показывает канал как «брокер» и персистентный журнал.

### 5. SQL: покупки до бана
DISTINCT user+SKU где `purchase.date < ban.date_from` (или нет бана); HAVING SUM > 5000. На собесе: JOIN + WHERE vs HAVING; индекс под фильтр по дате.
