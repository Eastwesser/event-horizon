## Задачи

### 1. `zip` двух слайсов
Склеить пары до `min(len)`. На собесе: заранее `make(..., 0, minL)`, не аллоцировать внутренний слайс «заранее на все».

### 2. `zip` N слайсов (`...[]int`)
Найти min длины по всем аргументам, на каждом индексе собрать «строку» значений. Краевой: ноль аргументов / пустой слайс.

### 3. Merge N каналов
По горутине на вход + `WaitGroup` закрывает out. Скажи: закрывать out только после drain всех; loop-var до 1.22 — передавай `ch` аргументом (или Go ≥1.22).

### 4. Тайминг двух worker()
Если сначала `ch1, ch2 := worker(), worker()` — оба спят параллельно → ~3с. Если `_, _ = <-worker(), <-worker()` — RHS слева направо → ~6с. На собесе различай эти два вызова.

### 5. Code-review валютного CLI (исправленная версия)
Звёзды: секреты в env, SQL injection → placeholders, один DB pool, баг `curFrom` дважды, guard clause, timeout у HTTP, не panic в цикле.
