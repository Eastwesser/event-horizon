# Урок 08 — 8 апреля 2026

HR / процессы: типы компаний, как собирать легенду опыта, поиск «реальных» мест (продукт / IT-продукт / аутсорс / аутстафф). Полный конспект: [`08_full_task.md`](./08_full_task.md). Демо якорит разговор про типы компаний.

## Что говорить на HR

### Типы компаний
Продуктовая (не IT-core) ≠ IT-продукт ≠ аутсорс ≠ аутстафф. Подбирай формулировки под сайт и ОКН/ОКВЭД.

### Легенда опыта
Прошлый неофициальный опыт / друзья / рынок. Среднее место — средне-крупная реальная; первое — стартап/ликвидированная (проверяй дату и вид деятельности).

### Поиск
«Тематика + автоматизация/разработка ПО» → кейсы с сайта в рассказ (не выдумывай стек, которого нет на карьерной странице).
