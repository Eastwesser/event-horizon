# ImageProcessor

Сервис для фоновой обработки изображений через Apache Kafka.

## Описание

ImageProcessor принимает изображения через HTTP API, помещает задачи на обработку в очередь Kafka и обрабатывает их в фоне. Поддерживает ресайз, генерацию миниатюр и добавление водяных знаков.

## Реализация

- HTTP API для загрузки, получения и удаления изображений
- Фоновая обработка через Apache Kafka
- Поддержка форматов: JPG, PNG, GIF
- Обработка: ресайз (800x600), миниатюры (200px), водяные знаки
- Файловое хранилище для исходных и обработанных изображений
- Веб-интерфейс для загрузки и просмотра результатов
- In-memory fallback для очереди при отсутствии Kafka

## Быстрый старт

1. Установите зависимости:
```bash
make install
```

2. Запустите Kafka (опционально):
```bash
make docker-up
```

3. Запустите приложение:
```bash
make run
```

4. Откройте браузер: http://localhost:8080
