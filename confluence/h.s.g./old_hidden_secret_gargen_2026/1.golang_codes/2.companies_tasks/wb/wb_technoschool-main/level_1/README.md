## Level 1 — Базовые задания

Короткие упражнения на синтаксис Go, строки, коллекции, простые алгоритмы. Каждый `task_N` содержит условие и лаконичное решение в `sol.go`.

Запуск: перейдите в нужную папку `task_N` и выполните `go run sol.go`.

### Краткие описания задач
- `task_1`: встраивание методов (embedded struct) — `Human` → `Action`.
- `task_2`: параллельное возведение чисел в квадрат (горутины).
- `task_3`: producer + N воркеров, читающих из канала.
- `task_4`: корректное завершение воркеров по Ctrl+C (context/канал).
- `task_5`: канал с таймером — завершение через N секунд.
- `task_6`: способы остановки горутин (канал, контекст, условие, Goexit).
- `task_7`: потокобезопасная map (Mutex или sync.Map), проверка -race.
- `task_8`: установка i-го бита в int64 (| и &^).
- `task_9`: двухэтапный конвейер x → 2x, корректное закрытие каналов.
- `task_10`: группировка температур по десяткам.
- `task_11`: пересечение множеств (без дубликатов).
- `task_16`: множество из набора строк (уникализация).
- `task_17`: swap двух чисел без temp (arith/XOR).
- `task_18`: определение типа переменной через type switch.
- `task_19`: проблема с срезом подстроки, копирование по рунам.
- `task_20`: быстрая сортировка (quick sort) среза.
 - `task_21`: паттерн Adapter (адаптер интерфейса к несовместимому типу).
 - `task_22`: арифметика больших чисел (+, -, *, /), при необходимости math/big.
 - `task_23`: удаление i-го элемента из слайса без утечки памяти.
 - `task_24`: расстояние между точками (Point, конструктор, метод Distance).
 - `task_25`: реализация sleep без time.Sleep (через time.After/канал).
 - `task_26`: проверка уникальности символов строки (Unicode, без учёта регистра).
