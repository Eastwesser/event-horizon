## Техношкола WB 2025 — Golang

Сборник решений задач Техношколы Wildberries 2025 (направление: горутиновый голэнг).

### Оглавление
- **О Техношколе WB**
- **Цель курса**
- **Структура репозитория**
- **Быстрый старт**
- **Ключевые задачи (Level 2)**

### О Техношколе WB
Практический курс по Go от Wildberries: серии задач от базовых конструкций до сетевых утилит и мини-сервисов. Упор на конкурентность, работу с ОС и HTTP.

### Цель курса
- Прокачать практические навыки: горутины, каналы, пайплайны, системные вызовы, сетевое взаимодействие, минимальные сервисы.
- Писать чистый и лаконичный код, прямо соответствующий ТЗ.

### Структура репозитория
- Уровни: `level_1/`, `level_2/`, ... — в каждом подпапки `task_N/`.
- Каждая задача содержит `README.md` (условие/запуск) и реализацию (`sol.go`) или мини-проект (например, `level_2/task_18`).
- Для больших задач — собственный модуль и несколько пакетов (см. `level_2/task_18`).

### Быстрый старт
- Откройте нужный `task_N/` и смотрите `README.md` задачи.
- Запуск простых задач: `go run sol.go` в директории задачи.
- Для задач-проектов смотрите раздел «Запуск/использование» их `README.md`.

### Уровни
- Подробности по задачам уровня смотрите в README соответствующего уровня:
  - `level_1/README.md` — краткие описания задач уровня 1.
  - `level_2/README.md` — ключевые задачи уровня 2 (утилиты и сервисы).
