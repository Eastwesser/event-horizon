## Тема
Контестные/собес-задачи на графы, строки, комбинаторику. Полные условия: [`tasks.md`](tasks.md).

## Runnable demos (interview-size)

| Pack | Что | Запуск |
|------|-----|--------|
| `code/01_min_cycle` | кратчайший простой цикл (BFS от каждой вершины) | ниже |
| `code/02_tbank_study` | мин. замен, чтобы были подстроки `tbank` и `study` | ниже |

```bash
export GOWORK=off
cd code/01_min_cycle && go run main.go
cd ../02_tbank_study && go run main.go
```

## Что говорить на собесе

- **min cycle:** «BFS от каждой вершины; back-edge даёт цикл длины `dist[u]+dist[v]+1`; берём минимум. Без кратных рёбер/петель». Сложность O((n+m)·n) — ок для n≤2500 на демо, на контесте уточни лимиты.
- **tbank/study:** «Перебор стартов обоих паттернов длины 5; при overlap — если в одной позиции разные буквы, пара невозможна; иначе считаем число несовпадений с `s`». Для |s|≤1e5 на контесте нужен более умный прекалкуляции mismatch-cost, здесь — interview brute.

## Hard contest vs interview demos

В `tasks.md` есть тяжёлые контестные задачи (подтаблица единиц, слоны, игра с бумажками и т.д.) — их **не** гоняем как `go run` демо. Для собеса достаточно двух packs выше + умение устно набросать идею остальных.

Полный список условий → [`tasks.md`](tasks.md).
