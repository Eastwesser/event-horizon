# GOMAXPROCS

## Грейд
18-19

## Вопрос
Что такое GOMAXPROCS? Зачем это нужно?

## Ответ
`GOMAXPROCS` — переменная, которая ограничивает количество потоков операционной системы, используемых Go-рантаймом для выполнения горутин.

## Дополнительные вопросы

### Может ли приложение с GOMAXPROCS=4 потреблять больше 4 ядер CPU?
**Да.** Это происходит из-за того, что Go Runtime запускает дополнительные потоки на блокирующие сисколы. В эти моменты количество используемых ядер может быть больше `GOMAXPROCS`.

## Что важно сказать на собеседовании

1. По умолчанию `GOMAXPROCS` равен количеству ядер CPU (или `runtime.NumCPU()`)
2. Гортины шедулятся на эти потоки (M:N scheduling)
3. При блокирующих системных вызовах (например, чтение файла) Go может создать дополнительный поток, чтобы не блокировать остальные горутины
4. `runtime.GOMAXPROCS(n)` — изменить значение
5. В Kubernetes контейнерах важно не оставлять значение по умолчанию (иначе Go увидит все CPU хоста, а не контейнера). Решение: `automaxprocs` от Uber

## Пример кода

```go
import "runtime"

func main() {
    fmt.Println("Default GOMAXPROCS:", runtime.GOMAXPROCS(0))
    runtime.GOMAXPROCS(2) // устанавливаем 2 потока
    fmt.Println("New GOMAXPROCS:", runtime.GOMAXPROCS(0))
}
```
