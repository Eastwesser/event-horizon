# pprof

## Грейд

## Вопрос
pprof. Что это такое и зачем нужно?

## Ответ

**pprof** — инструмент для профилирования Go-программ. Позволяет собирать и анализировать данные о производительности:

- **CPU profile** — где программа тратит процессорное время
- **Heap profile** — использование памяти (сколько аллоцировано)
- **Alloc profile** — история аллокаций (кто создаёт мусор)
- **Mutex profile** — contention на мьютексах
- **Block profile** — где горутины блокируются
- **Goroutine profile** — количество и стектрейсы горутин

## Дополнительные вопросы

### Как снять профили?

#### 1. Через `net/http/pprof`

```go
import _ "net/http/pprof"

func main() {
    go func() {
        log.Println(http.ListenAndServe("localhost:6060", nil))
    }()
    // ... основной код
}
```

Затем:

```bash
go tool pprof http://localhost:6060/debug/pprof/profile?seconds=30
go tool pprof http://localhost:6060/debug/pprof/heap
```

#### 2. Через runtime/pprof (для CLI-программ)
```go
f, _ := os.Create("cpu.prof")
pprof.StartCPUProfile(f)
defer pprof.StopCPUProfile()
```

### Что такое семплирующий профайлер?

Сохраняет не каждое событие, а каждое N-ное (например, каждые 100-й тик). 
CPU-профайлер в Go работает на основе сигналов (SIGPROF) — каждые 10 мс снимает стектрейс текущей горутины.

### Есть ли оверхед от использования pprof?
Heap, alloc, mutex, block — минимальный (данные собираются всегда)

CPU profile — добавляет оверхед (~1-5%), зависит от приложения

### Что такое trace и чем отличается от профилей?
Trace — запись событий во времени:

- Создание/блокировка/разблокировка горутин
- Syscalls
- Работа GC

### Взаимодействие с планировщиком

```bash
curl http://localhost:6060/debug/pprof/trace?seconds=5 > trace.out
go tool trace trace.out
```

Trace даёт более детальную картину, но оверхед выше.

### Как читать флеймграф (flame graph)?
Визуализация профиля:

- Горизонталь — время/память (шире → больше)
- Вертикаль — стек вызовов
- Цвета — случайные (для различия)
