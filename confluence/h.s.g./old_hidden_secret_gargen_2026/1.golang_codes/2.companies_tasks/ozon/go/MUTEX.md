# Мьютексы (Mutex)

## Грейд
17-18

## Вопрос
Что такое mutex и зачем он нужен?

## Ответ

**Mutex (Mutual Exclusion)** — примитив синхронизации для эксклюзивного доступа к разделяемому ресурсу. Если одному потоку нужен доступ к ресурсу, он блокирует мьютекс, остальные потоки ждут его освобождения.

### Виды мьютексов в Go

| Тип | Описание | Когда использовать |
|-----|----------|---------------------|
| **sync.Mutex** | Блокирует доступ полностью (и на чтение, и на запись) | Когда операций записи много |
| **sync.RWMutex** | Разделяет читателей и писателей | Когда чтение частей, запись — редко |

## Дополнительные вопросы

### Чем отличается RWMutex от Mutex?
- **Mutex** — только одна горутина может захватить блокировку (эксклюзивно)
- **RWMutex**:
  - `RLock()` — блокировка на чтение (много читателей одновременно)
  - `Lock()` — блокировка на запись (эксклюзивно, ждёт пока все читатели завершатся)

### Как устроен Mutex под капотом?
В Go — использует атомарные операции и futex (Fast Userspace Mutex) на Linux:
- `state` — 32-битное поле (биты для блокировки, счётчика ожидающих)
- `sema` — семафор для блокировки горутин

### Что такое spinlock и когда он используется?
**Spinlock** — блокировка, при которой поток не засыпает, а крутится в цикле, проверяя флаг.
- Используется для **очень коротких** критических секций
- В Go runtime используется внутри мьютексов на короткое время

## Что важно сказать на собеседовании

1. **Mutex не реентерабельный** — если горутина уже заблокировала мьютекс, повторный `Lock()` приведёт к deadlock'у

```go
mu.Lock()
mu.Lock()  // deadlock! (в одной горутине)
```
Всегда используйте defer mu.Unlock() — даже при панике блокировка освободится

```go
mu.Lock()
defer mu.Unlock()
// критическая секция
```

Не копируйте мьютекс — копирование sync.Mutex копирует состояние, что приводит к неожиданному поведению (защищено от go vet)

RWMutex может быть медленнее Mutex при высокой конкуренции — из-за когерентности кэша и сложной логики

Пример с RWMutex

```go
type Cache struct {
    mu   sync.RWMutex
    data map[string]string
}

func (c *Cache) Get(key string) string {
    c.mu.RLock()
    defer c.mu.RUnlock()
    return c.data[key]
}

func (c *Cache) Set(key, val string) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.data[key] = val
}
```
