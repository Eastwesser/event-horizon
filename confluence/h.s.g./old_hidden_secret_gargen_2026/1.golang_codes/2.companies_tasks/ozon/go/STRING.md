# Строки (Strings) в Go

## Грейд
17-18

## Вопрос
Что из себя представляет строка в Go?

## Ответ

**Строка** в Go — это **неизменяемый слайс байт** (read-only slice of bytes), который всегда в кодировке UTF-8.

### Внутреннее устройство

```go
type stringStruct struct {
    str unsafe.Pointer  // указатель на массив байт
    len int             // длина в байтах
}
```

### Дополнительные вопросы

Чем отличается байт от руны?

```text
Тип	Размер	Предназначение
byte	1 байт	ASCII символ или часть UTF-8 последовательности
rune	4 байта (int32)	Unicode code point (символ в кодировке UTF-32)
```


### Как итерироваться по строке?
```go
s := "Привет, мир!"

// По байтам (плохо для Unicode)
for i := 0; i < len(s); i++ {
    fmt.Printf("%c", s[i])  // 'Ð' '¿' ... — абракадабра!
}

// По рунам (правильно)
for i, r := range s {
    fmt.Printf("%d: %c (%U)\n", i, r, r)
}

// Получить срез рун
runes := []rune(s)
fmt.Println(len(runes))  // количество символов
```

### Как посчитать количество символов (рун) в строке?
```go
s := "Привет"
fmt.Println(len(s))              // 12 (байт)
fmt.Println(utf8.RuneCountInString(s)) // 6 (рун)
fmt.Println(len([]rune(s)))      // 6, но медленнее
```

### Как конвертировать строку в слайс байт и обратно?

```go
s := "hello"
b := []byte(s)   // копирует данные
b[0] = 'H'
s2 := string(b)  // "Hello"
```
Важно: преобразование string ↔ []byte копирует данные (O(n))

### Строки иммутабельны. Как тогда работает конкатенация?

```go
s := "Hello"
s += ", World"
```

Создаётся новая строка (выделяется новая память), старая остаётся до сборки мусора. 
Ну или юзай руны/strings.Builder если хочешь клеить строки.

### Эффективная конкатенация
```go
// Плохо: создаёт много промежуточных строк
s := ""
for i := 0; i < 1000; i++ {
    s += "a"
}

// Хорошо: strings.Builder
var builder strings.Builder
builder.Grow(1000)  // предвыделение памяти
for i := 0; i < 1000; i++ {
    builder.WriteString("a")
}
result := builder.String()
```

### Что важно сказать на собеседовании

- Строки иммутабельны — после создания их нельзя изменить
- Индексация строки (s[i]) возвращает байт, а не руну
- Range по строке итерирует по рунам
- len(s) возвращает количество байт, а не символов
- Пустая строка — "" (не nil)

### Примеры из задачи Ozon

```go
s := "test"
println(s[0])   // 116 (ASCII 't')
s[0] = 'R'      // compile error: cannot assign to s[0]
```
