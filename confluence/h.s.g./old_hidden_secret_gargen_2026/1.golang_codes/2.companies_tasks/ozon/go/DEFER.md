# Defer

## Грейд
17-19

## Вопрос
Что такое defer? Что выведет следующий код?

```go
type X struct {
    V int
}

func (x X) S() {
    fmt.Println(x.V)
}

func main() {
    x := X{123}
    defer x.S()
    x.V = 456
}
```

А что выведет этот код?

```go
func main() {
    x := X{123}
    defer func() { x.S() }()
    x.V = 456
}
```

### Ответ
Первый код: 123
Второй код: 456

## Почему

### Первый случай
defer x.S() — аргументы метода вычисляются в момент вызова defer, а не в момент выполнения.

x.S() привязан к конкретному экземпляру x с V = 123

Даже после изменения x.V = 456, отложенный вызов помнит старое значение

### Второй случай
defer func() { x.S() }() — замыкание захватывает ссылку на переменную x

При выполнении отложенной функции читается текущее значение x.V (456)

## Дополнительные вопросы

Что произойдёт, если написать несколько defer подряд?
Они вызовутся в обратном порядке (LIFO — стек).

```go
defer fmt.Println("1")
defer fmt.Println("2")
defer fmt.Println("3")
// Вывод: 3 2 1
```

В каких случаях defer не будет вызван?
- os.Exit(0)
- log.Fatal() (внутри вызывает os.Exit)
- Паника (но defer сработает до паники, а после — нет)

```go
func main() {
    defer fmt.Println("не вызовется?")
    os.Exit(0)
}
// Defer НЕ выполнится!
```

### Что будет, если в defer произойдёт паника?

- Если паника в defer, она перезапишет предыдущую панику (если была)
- Выполнение программы остановится

### Что важно сказать на собеседовании

- Defer гарантирует выполнение функции при выходе из текущей функции (даже при панике)
- Аргументы вычисляются сразу (в момент регистрации defer)
- Замыкания захватывают переменные по ссылке
- Defer работает LIFO

Используется для:
- Закрытия файлов/сетевых соединений
- Разблокировки мьютексов
- Recovery от паники

### Пример с recover

```go
func safeCall(f func()) {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered:", r)
        }
    }()
    f()
}
```
