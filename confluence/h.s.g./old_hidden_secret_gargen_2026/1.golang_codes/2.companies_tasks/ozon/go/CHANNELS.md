# Каналы (Channels)

## Грейд
18-19

## Вопрос
Что такое каналы? Зачем нужны? Какие они бывают?

## Ответ

**Каналы** — механизм взаимодействия (коммуникации) между горутинами в Go.
- Потокобезопасны — к одному каналу могут обращаться несколько горутин одновременно
- Следуют принципу: *"Don't communicate by sharing memory; share memory by communicating"*

### Типы каналов

| Тип | Создание | Поведение |
|-----|----------|-----------|
| **Небуферизированный (синхронный)** | `make(chan T)` | Отправка блокируется, пока другая горутина не получит значение |
| **Буферизированный (асинхронный)** | `make(chan T, capacity)` | Отправка блокируется только при заполненном буфере |

## Дополнительные вопросы

### Что произойдёт при чтении/записи в закрытый канал?
- **Чтение** — возвращает zero value и `false` (если используется `v, ok := <-ch`)
- **Запись** — вызывает **панику**

```go
ch := make(chan int)
close(ch)
v, ok := <-ch  // v = 0, ok = false
ch <- 1        // panic: send on closed channel
```
`
Что произойдёт при чтении/записи в nil-канал?
Чтение — блокируется навсегда
Запись — блокируется навсегда
Закрытие — паника

```go
var ch chan int  // nil
<-ch             // fatal error: all goroutines are asleep - deadlock!
ch <- 1          // то же самое
close(ch)        // panic: close of nil channel
```

### Как устроен канал внутри?

Структура hchan (8 полей) в runtime:

- qcount — количество элементов в буфере
- dataqsiz — размер буфера
- buf — указатель на кольцевой буфер
- elemsize — размер элемента
- closed — флаг закрытия
- sendx, recvx — индексы для отправки/получения
- recvq, sendq — очереди ожидающих горутин
- lock — мьютекс для безопасного доступа

### Что такое select и как он работает?

select — это switch для каналов. Позволяет ждать на нескольких каналах одновременно.

```go
select {
case msg1 := <-ch1:
    fmt.Println(msg1)
case msg2 := <-ch2:
    fmt.Println(msg2)
case <-time.After(1 * time.Second):
    fmt.Println("timeout")
default:
    fmt.Println("no data")
}
```

Паттерны с каналами
```text
Паттерн	            Описание

Generator	    Функция возвращает канал и запускает горутину
Fan-In	            Объединение нескольких каналов в один
Fan-Out	            Рассылка из одного канала в несколько
Pipeline	    Последовательная обработка через несколько горутин
Worker Pool	    Пул воркеров, читающих из общего канала
Ticker	            Периодические события (time.Tick)
Done channel	    Сигнал завершения (<-done)
```
