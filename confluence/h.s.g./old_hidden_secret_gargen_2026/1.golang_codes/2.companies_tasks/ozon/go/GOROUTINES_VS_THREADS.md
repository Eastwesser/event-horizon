# Горутины vs Потоки

## Грейд
17

## Вопрос
Чем горутины отличаются от потоков?

## Ответ

| Характеристика | Горутина | Поток ОС |
|----------------|----------|----------|
| **Размер стека** | Небольшой (2-8 КБ), динамический | Большой (1-8 МБ), фиксированный |
| **Количество** | Тысячи/миллионы | Сотни (ограничено памятью) |
| **Шедулинг** | User-space (Go runtime) | Kernel-space (ОС) |
| **Переключение контекста** | Дешевле (не нужно переключать режимы) | Дороже (user↔kernel) |
| **Создание/уничтожение** | Очень быстро | Медленно |

## Дополнительные вопросы

### Что такое GOMAXPROCS?
Переменная, ограничивающая количество потоков ОС, используемых Go-рантаймом для выполнения горутин.

```go
runtime.GOMAXPROCS(4)  // Go использует максимум 4 потока ОС
```

### Как происходит шедулинг горутин?
```text
M (Machine) — поток ОС
P (Processor) — логический процессор (количество = GOMAXPROCS)
G (Goroutine) — горутина
```

Схема: G → P → M

Планировщик использует work stealing: если у P нет работы, он крадёт G у других P

### Сколько горутин можно создать?
Теоретически — сколько хватит памяти. Практически:

Каждая горутина ~2 КБ стека

1 млн горутин ≈ 2 ГБ памяти

### Что такое "стек горутины"?
Изначально маленький (2 КБ), может расти до 1 ГБ (64-bit) при необходимости. Рост происходит в куче.

### А что со стеком потока?
Фиксированный размер (обычно 1-8 МБ), не может динамически увеличиваться.

Пример
```go
// Создаём 100 000 горутин — легко!
for i := 0; i < 100000; i++ {
    go func(n int) {
        time.Sleep(time.Second)
        fmt.Println(n)
    }(i)
}
```

### Что важно сказать на собеседовании

- Горутины легковесные — можно создавать сотни тысяч
- Шедулинг в user-space — быстрее, нет переключения в kernel
- GOMAXPROCS = количество параллельно работающих горутин (не общее количество)
- Блокирующие сисколлы — Go создаёт дополнительный поток, чтобы не блокировать остальные горутины
- Горутины дешевле не только по памяти, но и по времени создания/переключения
