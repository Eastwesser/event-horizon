# Rate Limiter

## Грейд
18-19

## Вопрос
Мой сервис использует внешний API для построения маршрутов. В рамках тарифа у нас есть ограничение по RPS. Нужно спроектировать rate limiter.

## Ответ
Есть два основных варианта:

### 1. С использованием внешнего хранилища (Redis)
Храним счётчик запросов за нужное окно в Redis.

**Плюсы:**
- Простая реализация и конфигурация
- Не имеет значения, насколько сбалансированы запросы по инстансам

**Минусы:**
- Увеличение времени запроса (сетевой вызов)
- Единая точка отказа (Redis)

### 2. Без внешнего хранилища
Каждый инстанс имеет ограничение `x / n`, где `x` — общее количество запросов, а `n` — количество инстансов.

**Плюсы:**
- Нет единой точки отказа
- Нет дополнительных задержек

**Минусы:**
- Сложно конфигурировать
- Балансировка запросов имеет большое значение

## Дополнительные вопросы

### Как можно оптимизировать работу с Redis?
Использовать Lua-скрипт, который будет возвращать `true/false` атомарно.

## Что важно сказать на собеседовании

1. **Алгоритмы rate limiting:**
    - Fixed Window (простой, но может пропустить burst в конце окна)
    - Sliding Window (точнее, но сложнее)
    - Token Bucket (позволяет burst'ы)
    - Leaky Bucket (сглаживает трафик)

2. **Где хранить состояние:**
    - In-memory (для одного инстанса)
    - Redis (для распределённой системы)
    - БД (для персистентности, но медленно)

3. **HTTP-заголовки для rate limiting:**
    - `X-RateLimit-Limit` — лимит на окно
    - `X-RateLimit-Remaining` — осталось запросов
    - `X-RateLimit-Reset` — время сброса

4. **Код состояния:** `429 Too Many Requests`

## Пример (Token Bucket in-memory)

```go
type TokenBucket struct {
    rate     float64 // токенов в секунду
    capacity float64 // макс. токенов
    tokens   float64
    lastTick time.Time
    mu       sync.Mutex
}

func (tb *TokenBucket) Allow() bool {
    tb.mu.Lock()
    defer tb.mu.Unlock()
    now := time.Now()
    elapsed := now.Sub(tb.lastTick).Seconds()
    tb.tokens = min(tb.capacity, tb.tokens+elapsed*tb.rate)
    tb.lastTick = now
    if tb.tokens >= 1 {
        tb.tokens--
        return true
    }
    return false
}
```
