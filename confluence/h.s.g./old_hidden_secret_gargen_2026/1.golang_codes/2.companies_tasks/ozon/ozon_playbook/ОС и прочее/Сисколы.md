Вызов какой-то функции в ОС, ну а по сути интерфейс между приложением и ядром. при сисколе у нас происхзодит переключение из юзер спейс в кернел спейс после чего система выполняет действия 
●     Открыть файл (open)
●     Закрыть файл (close)
●     Прочитать файл (read)
●     Записать файл (write)
●     Создать процесс (fork)
●     Создать поток (thread)
●     Создать сокет (socket)
●     Привязать сокет (bind)
●     Слушать сокет (listen)
●     Принять сокет (accept)
●     Подключить сокет (connect)
●     Отправить в сокет (send)
●     Получить из сокета (recv)

Процесс - выолняющаяся задача в ОС, по сути единица работы в ОС. у проуцесса свое адресное пространство, есть пиды.
