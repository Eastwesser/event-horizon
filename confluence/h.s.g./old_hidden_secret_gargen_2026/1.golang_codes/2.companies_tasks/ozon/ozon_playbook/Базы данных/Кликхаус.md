### **Полноценные транзакции (ACID)**

- В ClickHouse **нет** поддержки классических транзакций с `COMMIT`/`ROLLBACK`.
    
- Нет механизма изоляции транзакций (уровни `READ COMMITTED`, `REPEATABLE READ` и т.д.).
    
- Данные сразу становятся видимыми после вставки (аналог `AUTOCOMMIT`).

ClickHouse изначально заточен под **аналитику** и **добавление данных**, а не их изменение.
    
- Операции `UPDATE` и `DELETE` появились только в поздних версиях (через мутации), но работают **медленно** (перезаписывают целые куски данных).

 В ClickHouse **нет** B-деревьев (как в PostgreSQL), которые эффективны для точечных запросов.
    
- Основной индекс — **первичный ключ** (PARTITION BY + ORDER BY), работающий только для больших диапазонов данных.
    
- Нет поддержки индексов для ускорения `JOIN` или произвольных условий `WHERE`.

CREATE DATABASE test_db;
USE test_db;

-- Простая таблица с движком MergeTree (основной для аналитики)
CREATE TABLE events (
    event_date Date,
    event_time DateTime,
    user_id UInt32,
    event_name String,
    value Float64
) ENGINE = MergeTree()
ORDER BY (event_date, user_id);  -- Первичный ключ (для сортировки)


**А вот тут почему он супер быстрый**

SELECT * FROM events;

-- Агрегации (ClickHouse очень быстрый на этом!)
SELECT 
    event_date,
    count() AS events_count,
    sum(value) AS total_value
FROM events
GROUP BY event_date;

|   |   |   |
|---|---|---|
|**MergeTree**|Основной для аналитики. Поддержка партиций, индексов.|`ENGINE = MergeTree() ORDER BY (date, id)`|
|**ReplacingMergeTree**|Автоматически удаляет дубликаты (по ключу сортировки).|`ENGINE = ReplacingMergeTree() ORDER BY id`|
|**SummingMergeTree**|Автоматически суммирует значения при слиянии данных.|`ENGINE = SummingMergeTree() ORDER BY date`|
### **Пример партиционирования**
CREATE TABLE logs (
    log_date Date,
    message String,
    level String
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(log_date)  -- Партиции по месяцу
ORDER BY (level, log_date);

> Партиции ускоряют выборку и управление данными (можно удалять целые партиции: `ALTER TABLE logs DROP PARTITION '202310'`).
