Какие типы локов (блокировок) есть в PostgreSQL? Кто берет эти локи?

ОТВЕТ:
Лок на таблицу, лок на запись, пользовательские (рекомендательные) локи.

например: FOR UPDATE, который конфликтует сам с собой
Например:SELECT берет лок на таблицу типа ACCESS SHARE, который конфликтует, например, с самым строгим ACCESS EXCLUSIVE.
еще есть: for shared, for 
1. **ROW EXCLUSIVE** - Берется при UPDATE, DELETE, INSERT.
2. **ROW SHARE** - Берется при SELECT FOR UPDATE/SHARE.
3. **EXCLUSIVE** - Блокирует все операции кроме ACCESS SHARE.


Какие аномалии могут быть при исполнении несколько транзакций параллельно? Расскажи кратко о них.

ОТВЕТ:
DIRTY READ - Транзакция читает **незакоммиченные данные** из другой транзакции.
NON REPEATABLE READ - Повторное чтение одних и тех же данных в рамках одной транзакции возвращает **разные значения**, потому что другая транзакция их изменила.
PHANTOM READ - Появление **новых строк** между повторными чтениями в одной транзакции.
