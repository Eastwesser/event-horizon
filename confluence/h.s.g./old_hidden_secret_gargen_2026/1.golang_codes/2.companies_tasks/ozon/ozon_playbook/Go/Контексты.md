механизм для управления **жизненным циклом операций**, особенно в асинхронных или распределённых системах (например, HTTP-запросах, горутинах, базах данных).

### **Ключевые идеи контекста в Go:**

1. **Отмена операций** (Cancellation):
    
    - Передача сигнала на прекращение работы (например, если пользователь отменил HTTP-запрос).
    ctx, cancel := context.WithCancel(context.Background())
    go func() {
        time.Sleep(2 * time.Second)
        cancel() // Принудительная отмена
    }()
    select {
    case <-ctx.Done():
        fmt.Println("Операция отменена!")
    }
    
2. **Таймауты** (Timeouts):
    
    - Автоматическая отмена операции, если она не завершилась за заданное время.
    ctx, cancel := context.WithTimeout(context.Background(), 1 * time.Second)
    defer cancel()
    // Если операция длится >1 сек — получим ctx.Done()
    
3. **Дедлайны** (Deadlines):
    
    - Конкретная временная метка для завершения (аналогично таймауту, но с привязкой к времени).
    ctx, cancel := context.WithDeadline(context.Background(), time.Now().Add(3 * time.Second))
    
4. **Передача значений** (Values):
    
    - Контекст может хранить метаданные (например, ID запроса, токены).
    ctx := context.WithValue(context.Background(), "requestID", "12345")
    fmt.Println(ctx.Value("requestID")) // "12345"
    

### **Где используется?**

- **HTTP-серверы** (передача контекста в хендлеры).
    
- **Горутины** (контроль утечек через отмену).
    
- **Базы данных** (отмена долгих запросов).
    
- **GRPC** (сквозная передача параметров).
