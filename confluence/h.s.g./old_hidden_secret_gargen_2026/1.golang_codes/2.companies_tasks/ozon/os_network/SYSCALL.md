## Вопрос
Что такое сисколл (syscall)?

## Ответ

**Системный вызов (syscall)** — вызов функции операционной системы из пользовательского приложения. Например, чтение файла, создание процесса, отправка данных по сети.

## Дополнительные вопросы

### Что происходит во время вызова сискола?
Происходит **переключение из User Space в Kernel Space**, после чего система выполняет необходимые действия. Это переключение требует сохранения контекста и стоит дорого (сотни наносекунд).

### Что делает сисколл fork?
Создаёт **копию текущего процесса** (родительский и дочерний процессы). В дочернем процессе `fork()` возвращает 0, в родительском — PID дочернего.

### Что делает сисколл epoll?
Позволяет **асинхронно получать события** о том, что из файлового дескриптора можно читать/писать. Используется для масштабируемого сетевого ввода-вывода (десятки тысяч соединений в одном потоке).

## Что важно сказать на собеседовании

### Основные группы сисколов

| Группа | Примеры |
|--------|---------|
| Управление процессами | `fork`, `exec`, `wait`, `exit` |
| Файловая система | `open`, `read`, `write`, `close`, `stat` |
| Сеть | `socket`, `bind`, `listen`, `accept`, `connect` |
| Управление памятью | `mmap`, `brk`, `mprotect` |
| IPC | `pipe`, `shmget`, `msgget`, `semget` |

### Как Go обрабатывает блокирующие сисколы?
Go рантайм оборачивает блокирующие сисколы так, чтобы они не блокировали другие горутины. Например, при `read()` на сокете, Go может переключить горутину, а поток ОС остаётся заблокированным.

### Стоимость сискола
- User→Kernel переключение: ~100-200 нс (без учёта работы)
- Для `read()` на диске: миллисекунды (сам ввод-вывод)
