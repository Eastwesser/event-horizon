# Файловые дескрипторы (File Descriptor)

## Грейд
18-20

## Вопрос
Что такое файловый дескриптор?

## Ответ

**Файловый дескриптор** — это идентификатор (неотрицательное целое число), который операционная система выдаёт процессу при открытии файла. Используется для чтения, записи и других операций.

Это универсальный механизм для работы с разными сущностями:
- Реальные файлы на диске
- Виртуальные файлы (procfs, sysfs)
- Устройства ввода/вывода
- Паттерны (pipe)
- Сокеты
- epoll инстансы

## Дополнительные вопросы

### Что такое stdin/stdout/stderr и какие дескрипторы для них назначены?
- `stdin` (стандартный ввод) — дескриптор **0**
- `stdout` (стандартный вывод) — дескриптор **1**
- `stderr` (стандартный вывод ошибок) — дескриптор **2**

При запуске приложения из консоли stdout/stderr обычно перенаправляются в терминал.

### Задачка: `du/df` показывает, что место в файловой системе есть, а записать ничего нельзя («нет места»). Почему и как исправить?

**Причина:** При удалении файла реальное освобождение пространства происходит только при закрытии дескрипторов **всеми приложениями**. Если процесс держит открытый файл и удалить его из файловой системы, он всё равно занимает место.

**Решение:** Найти программу, которая держит дескрипторы удалённого файла (`lsof | grep deleted`), и заставить её отпустить их (перезапустить или отправить сигнал).

## Что важно сказать на собеседовании

### Таблица файловых дескрипторов
У каждого процесса есть своя таблица FD. При вызове `open()` или `socket()` ОС добавляет запись в эту таблицу и возвращает индекс (число).

### Ограничения
- `ulimit -n` — максимальное количество открытых FD для процесса (обычно 1024)
- Можно увеличить (`ulimit -n 65535`)

### Утечка FD
Если процесс постоянно открывает файлы/сокеты и не закрывает их, рано или поздно он достигнет лимита и начнёт получать ошибки `"too many open files"`.

### Команды для диагностики

```bash
lsof -p <pid>           # показать FD процесса
ls -la /proc/<pid>/fd   # альтернатива
cat /proc/sys/fs/file-max  # системный лимит
```
