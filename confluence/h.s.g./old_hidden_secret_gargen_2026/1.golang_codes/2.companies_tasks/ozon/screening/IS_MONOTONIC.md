# IS_MONOTONIC

Проверить, что слайс **монотонный**: либо неубывает, либо невозрастает (равные элементы допустимы).

Примеры:
- `{1,7}`, `{1,1}`, `{3,3,1}`, `{9,5,1}` → true
- `{23,5,23}` → false
- пустой / один элемент → true

Идея: два флага `inc`/`dec`, early exit когда оба false.
