# ZIP

`zip(s1, s2 []int) [][]int` — пары элементов до длины **короткого** слайса.

```
zip({1,2,3}, {4,5,6,7,8}) → [[1 4] [2 5] [3 6]]
```

Без паники на разной длине; пустой вход → пустой результат.
