# STACK ALGORITHM

## Суть паттерна
Стек (LIFO) — структура, где последний пришёл — первый ушёл.
Идеален для проверки вложенных структур: скобки, HTML-теги, парсинг выражений.

---

## Классический шаблон (Go)

```go
stack := []rune{}  // стек на слайсе

// положить в стек
stack = append(stack, value)

// достать из стека (последний)
last := stack[len(stack)-1]
stack = stack[:len(stack)-1]

// проверить, пуст ли стек
isEmpty := len(stack) == 0
```

## Задача 1: Проверка валидности скобок

**Условие:**  
Дана строка, содержащая символы `()[]{}`. Нужно определить, корректно ли расставлены скобки.

**Решение (классика):**

```go
func isValid(s string) bool {
stack := []rune{}

    pairs := map[rune]rune{
        ')': '(',
        ']': '[',
        '}': '{',
    }
    
    for _, ch := range s {
        if opening, ok := pairs[ch]; ok {
            if len(stack) == 0 || stack[len(stack)-1] != opening {
                return false
            }
            stack = stack[:len(stack)-1]
        } else if ch == '(' || ch == '[' || ch == '{' {
            stack = append(stack, ch)
        }
    }
    
    return len(stack) == 0
}
```

**Сложность:** O(n) time, O(n) memory в худшем случае (вся строка — открывающие скобки)

**Примеры:**
- `"([])"` → `true`
- `"([)]"` → `false`
- `"((()))"` → `true`

**Почему стек?**  
Открывающие скобки ждут свою пару. Последняя открытая должна закрыться первой. Это ровно LIFO-поведение.
