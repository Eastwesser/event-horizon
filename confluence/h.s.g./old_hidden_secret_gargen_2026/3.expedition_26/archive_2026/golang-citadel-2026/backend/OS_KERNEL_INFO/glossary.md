# Глоссарий

| Термин | Что значит |
|--------|-------------|
| **execve** | Системный вызов, заменяющий образ процесса на новый бинарник |
| **clone** | Системный вызов для создания потока (легковесного процесса) |
| **mmap** | Системный вызов для управления виртуальной памятью |
| **ELF** | Executable and Linkable Format — формат бинарников в Linux |
| **PIE** | Position Independent Executable — можно загрузить по любому адресу (ASLR) |
| **VMA** | Virtual Memory Area — регион виртуальной памяти процесса |
| **VmSize** | Виртуальная память процесса (все резервации) |
| **VmRSS** | Resident Set Size — физическая RAM, реально используемая |
| **Page fault** | Исключение при обращении к виртуальной странице без физической |
| **Shebang** | `#!` в начале скрипта — указывает интерпретатор |
| **Goroutine** | Легковесный поток в Go (стек 2KB) |
| **GOMAXPROCS** | Количество P (логических процессоров) |
| **GMP** | Goroutine → Machine → Processor (модель планировщика Go) |
| **syscall** | Программное прерывание для вызова функций ядра |
| **futex** | Fast userspace mutex — примитив синхронизации в Linux |
| **epoll** | Масштабируемый механизм I/O мультиплексирования |
| **Arena** | 64MB кусок heap в Go |
| **Span** | 8KB кусок внутри арены |
