Как воспроизвести:

bash
# 1. Создаем топик с 3 партициями
docker exec carton-kafka kafka-topics --create \
  --topic experiment.lag \
  --bootstrap-server localhost:9092 \
  --partitions 3 \
  --replication-factor 1

# 2. Запускаем producer (10K msg/s)
./scripts/kafka-producer --topic experiment.lag --rate 10000

# 3. Запускаем slow consumer (5K msg/s)
./scripts/kafka-consumer --topic experiment.lag --rate 5000

# 4. Наблюдаем lag в Kafka UI
open http://localhost:8080

🖥️ 4. Docker Compose vs Minikube — что выбрать для старта
Сравнение по метрикам
Параметр	Docker Compose	Minikube
Время запуска	30 сек	2-3 мин
Потребление RAM (базовое)	~500 MB	~2 GB
Сложность настройки	Низкая	Средняя
