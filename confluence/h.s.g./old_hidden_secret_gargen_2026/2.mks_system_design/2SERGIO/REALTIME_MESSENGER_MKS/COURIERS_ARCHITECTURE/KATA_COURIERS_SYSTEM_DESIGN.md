Проблемы, которые возникли:

RPS вырос → PostgreSQL не справляется с write нагрузкой (3000+ location updates/sec)

Latency выросла → чтение locations стало медленным из-за большого объема данных

Customer App timeout → 50ms SLA не соблюдается (реальная latency 200-500ms)

Order Service dependency → синхронные вызовы к Logistics Service создают каскадные задержки

🔄 5. Применимость к твоим проектам
5.1. Как это ложится на Gift / Time
Паттерн из Courier Labs	Применение в Gift / Time
Location updates → Kafka	Generation events → Kafka (генерация картинки не блокирует пользователя)
Redis cache for fast reads	Redis cache for generation results (частые запросы одного дизайна)
WebSocket for real-time	WebSocket для чатов с дизайнерами (уже в архитектуре)
Multiple consumers	Generation Service → Analytics, Notification, Order
Spatial queries → Redis	Design templates → Redis (популярные шаблоны)
