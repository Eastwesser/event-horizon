📚 Расшифровка аббревиатур

Аббревиатура	Расшифровка	Что означает
OLTP	Online Transaction Processing	Обработка транзакций в реальном времени — много маленьких операций (INSERT/UPDATE/SELECT)
OLAP	Online Analytical Processing	Обработка аналитических запросов — большие объемы данных, агрегации, отчеты
🏗️ Как это реализовано в EventHorizon

🔵 OLTP (Transaction Processing) — Работает здесь и сейчас

Назначение: Быстрые, частые операции, которые должны выполняться за миллисекунды.

Сервис	Тип данных	Нагрузка
Auth	Регистрация, логин, JWT	~1k RPS (пик)
Game	Отправка рекордов, валидация ходов	~10k RPS
Billing	Начисление лампочек/билетиков	~10k RPS
Leaderboard	Обновление топа, чтение	~10k RPS чтение + запись
Хранилище: PostgreSQL (ACID, транзакции) + Redis (кэш, сессии, топ)

sql
-- Пример OLTP-запроса: обновление баланса пользователя
UPDATE user_currencies SET balance = balance + 10 WHERE user_id = '...' AND currency_type = 'lamps';
🟢 OLAP (Analytical Processing) — Пока не реализовано, но планируется

Назначение: Аналитика, дашборды, метрики, поиск паттернов.

Что хотим анализировать	Откуда берём	Как будем хранить
DAU / MAU	Логины (Auth)	ClickHouse (в плане)
Ретеншн игроков	События логинов и игр	ClickHouse
Топ-игры по популярности	Game Submits	ClickHouse / PostgreSQL с агрегациями
Средний счёт по играм	Game Submits	ClickHouse
Распределение по времени	Всё	ClickHouse
Хранилище: ClickHouse (колоночная БД для аналитики) или PostgreSQL с партиционированием.

sql
-- Пример OLAP-запроса: DAU за последние 30 дней
SELECT 
    DATE(created_at) as day,
    COUNT(DISTINCT user_id) as dau
FROM events
WHERE created_at > NOW() - INTERVAL '30 days'
GROUP BY day
ORDER BY day;
📊 Сравнение OLTP vs OLAP в EventHorizon

Критерий	OLTP	OLAP
Назначение	Оперативная работа	Аналитика, отчеты
Скорость	Миллисекунды	Секунды/минуты
Запросы	Простые (по индексу)	Сложные (агрегации, JOIN)
Объем данных	Маленький (текущие данные)	Большой (история)
Частота	Тысячи в секунду	Десятки в день
Хранилище	PostgreSQL + Redis	ClickHouse
Статус в проекте	✅ Реализован	❌ В планах
