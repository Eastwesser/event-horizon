## 🏗️ Архитектурное Видение (Контекст)
### Основные Сущности
- **Gateway (API Gateway)**: Точка входа (Frontend on 5173 → Load Balancer → 3 Gateway instances). Маршрутизирует запросы к микросервисам.
- **Auth Service (IAM)**: **Критический компонент к доработке**. Сейчас любой пользователь — админ. Требуется реализовать строгое разделение: **Admin**, **User**, **Author**. Redis — хранилище для авторизационных ключей. Postgres — основная БД.
- **NATS JetStream**: Основная шина данных (Message Bus). Используется для асинхронного взаимодействия (Pub/Sub).
- **Kafka**: Написана в коде, но **не используется** в продакшене. Нужен адаптер для легкого переключения между NATS и Kafka (Backup/Bactrack). Основной упор — на NATS.

### Портовая Дисциплина (Критично!)
