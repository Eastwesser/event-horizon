### 🔴 ПРИОРИТЕТ 1: БЕЗОПАСНОСТЬ И ЦЕЛОСТНОСТЬ

#### 1.1 Исправить SQL-инъекции в ClickHouse
- **Где**: `services/analytics/...` (HTTP клиент)
- **Проблема**: строковая конкатенация + `escape()`
- **Решение**: переписать на параметризованные запросы (CH поддерживает `?` placeholders)
- **Проверка**: написать тест, который пытается вставить `'; DROP TABLE ...` — должно не работать

#### 1.2 Довести RBAC до e2e
- **Где**: Gateway + Auth + все сервисы
- **Проблема**: роли проверяются только в Inventory, не везде
- **Решение**:
  1. В Gateway — middleware `RequireRole()` для всех админских и авторских ручек
  2. В каждом gRPC сервисе — interceptor, проверяющий `role` из контекста
  3. В Auth — добавить эндпоинт для смены роли (только для admin)
- **Проверка**: написать интеграционный тест, который пытается вызвать админскую ручку с токеном user'а → 403

#### 1.3 Добавить Optimistic Locking (version)
- **Где**: все таблицы, где есть конкурентные обновления (balances, inventory, items, shop_items)
- **Решение**:
  ```sql
  ALTER TABLE balances ADD COLUMN version INT DEFAULT 1;
  UPDATE balances SET amount = amount + $1, version = version + 1 
  WHERE user_id = $2 AND currency = $3 AND version = $4;
Проверка: написать тест с двумя параллельными обновлениями → один получает ошибку конфликта
