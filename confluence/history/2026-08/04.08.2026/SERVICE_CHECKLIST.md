📋 ШАБЛОН РЕВЬЮ НОВОГО СЕРВИСА (Inventory / любой другой)
Когда получишь код, проверь по этому чек-листу:

🔍 Структура и архитектура
□ Есть ли cmd/main.go с инициализацией?
□ Есть ли internal/ с изоляцией внутренних пакетов?
□ Протокол: gRPC (proto) или HTTP? Если gRPC — есть ли proto/?
□ Конфиг: вынесен ли в config.go или .env?
🗄️ База данных
□ Есть ли миграции (migrations/ с +goose Up/Down)?
□ Используется ли транзакции для составных операций?
□ Есть ли индексы на внешние ключи и поля для поиска?
□ Используется ли Redis для кеширования (если нужно)?
🔗 Интеграции
□ Подключение к NATS (если есть события)?
□ Подключение к другим сервисам через gRPC?
□ Graceful shutdown (ловим SIGTERM, закрываем соединения)?
🧪 Тестирование и мониторинг
□ Есть ли health-эндпоинт (/health)?
□ Есть ли метрики (Prometheus)?
□ Есть ли базовые unit-тесты?
