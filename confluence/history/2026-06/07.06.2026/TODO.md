Towers (Башенки) — классическая аркада, где блоки едут слева и справа, а игрок должен вовремя нажать, чтобы положить блок на башню. Чем точнее, тем больше башня. Чем выше — тем быстрее едут блоки.

Отличная идея сделать 3D! Но давай трезво оценим.

Концепция: 3D vs 2D

Аспект	2D (Canvas)	3D (Three.js)
Сложность	🟢 Низкая	🔴 Высокая
Время реализации	2-3 часа	6-8 часов
Совместимость	✅ Отлично	⚠️ Может лагать на виртуалке
Интеграция с проектом	✅ Просто	🟡 Сложнее (камера, свет, материалы)
Моё предложение: Начнём с 2D, но сделаем его стильным — с псевдо-3D эффектом (изометрия или тени). Потом, если захочешь, можно будет переделать на Three.js.

Формула расчёта новой ширины

typescript
function calculateNewWidth(
  towerWidth: number,    // ширина последнего блока в башне
  blockX: number,        // позиция падающего блока (левый край)
  gameWidth: number      // ширина игрового поля
): number {
  const blockCenter = blockX + towerWidth / 2;
  const towerCenter = (gameWidth - towerWidth) / 2;
  const overlap = towerWidth - Math.abs(blockCenter - towerCenter);
  
  return Math.max(0, overlap);
}
