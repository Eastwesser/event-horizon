Gateway — полный разбор для собеса
Разбираю так же, как предыдущие. Всё, что известно по services/gateway из твоих файлов. 41 паттерн — самый богатый сервис. Через него идёт весь HTTP-трафик.

1. Одна фраза (elevator pitch)
Gateway — единственная публичная HTTP-точка. React → Balancer :8079 → Gateway ×3 (:8081–8083) → gRPC-сервисы. На каждом закрытом запросе зовёт Auth ValidateToken (JWT + Redis session), кладёт user_id + role в контекст. Circuit Breaker + Bulkhead на всех gRPC-клиентах: после серии ошибок — быстрый 503, half-open через 10s. Retry Interceptor с full jitter. Sliding Window Rate Limiter в Redis: login 5/s IP (fail-closed), общий ~100/s (fail-open). WebSocket Ticket Auth — одноразовый билет вместо JWT в query. BFF (Backend For Frontend) — один HTTP-контракт, DTO Mapper. Docs Gate — /docs 404 без DOCS_PASSWORD. 41 паттерн. God-function runGateway — техдолг.

4. Как работает (по шагам)
Request lifecycle (закрытый запрос)
React → Balancer :8079 → Gateway ×3 (:8081–8083).

Rate Limiter (Sliding Window в Redis):

login 5/s IP (fail-closed: Redis упал — не пускает)

общий ~100/s user/IP (fail-open: Redis упал — пускает)

WS 100 conn/min IP

RequireAuth: вырезает Authorization: Bearer, зовёт Auth gRPC ValidateToken.

Auth проверяет JWT + jti в Redis. Нет — 401.

RequireRole: проверяет роль из контекста. Нет — 403.

Circuit Breaker + Bulkhead: если gRPC-сервис болен — быстрый 503 (half-open через 10s, MaxRequests 3).

Retry Interceptor с full jitter: на transient-ошибки — retry.

DTO Mapper: proto ↔ JSON (с omitempty fix).

gRPC-вызов в доменный сервис.

gRPC → HTTP Error Mapping: InvalidArgument → 400, Unauthenticated → 401, PermissionDenied → 403, NotFound → 404, AlreadyExists/Aborted → 409, ResourceExhausted → 429, Unavailable → 503, Internal → 500.

Ответ клиенту.

Circuit Breaker + Bulkhead
Circuit Breaker: после серии ошибок (5xx / timeout) — Open. Запросы не идут в gRPC, сразу 503 service temporarily unavailable.

Half-Open через 10s: пропускает 3 запроса. Если успех — Closed. Если ошибка — Open снова.

Bulkhead: отдельные пулы на разные gRPC-клиенты. Если Billing тормозит — Shop не страдает.

В EVENT_HORIZON_PATTERNS_15.10.2026.md: «Circuit Breaker + Bulkhead — единственный сервис с этим».

Retry Interceptor с full jitter
На transient-ошибки (Unavailable, timeout) — retry.

Full jitter: задержка = random(0, base * 2^attempt). Не фиксированная, не exponential без jitter.

Full jitter размазывает retry-шторм: тысячи клиентов не бьют одновременно.

В каталоге: «Retry Interceptor с full jitter — gateway».

Rate Limiter (Sliding Window)
Sliding Window в Redis: ключ rate:{user_or_ip}:{path}, счётчик с окном.

Login 5/s IP — fail-closed (Redis упал → не пускает). Брутфорс важнее не пустить.

Общий ~100/s user/IP — fail-open (Redis упал → пускает). Лимитер не должен погасить весь вход.

WS 100 conn/min IP — защита от reconnect-шторма.

В каталоге: «Sliding Window Rate Limiter — gateway».

WebSocket Ticket Auth
Браузер → POST /api/v1/ws-ticket с Authorization: Bearer.

Gateway кладёт в Redis ключ ws:ticket:{id} на 30s, отдаёт {ticket, expires_in}.

Сокет открывается как GET /ws/leaderboard?ticket=.

Билет удаляется первым GETDEL — второй раз недействителен.

?token= с JWT — 401 (защита от утечки через query-параметры).

Origin проверяется (тот же хост, localhost, WS_ALLOWED_ORIGINS).

В каталоге: «WebSocket Ticket Auth — gateway».

BFF (Backend For Frontend)
Gateway — BFF: один HTTP-контракт для FE, gRPC для внутренних сервисов.

DTO Mapper: proto ↔ JSON. omitempty fix — proto3 не отличает «пустое» от «не установлено», DTO Mapper это исправляет.

Partial Response Fallback: если один из источников (Billing, Game) недоступен — Profile отдаёт _partial: true. Gateway это проксирует.

В каталоге: «BFF (Backend For Frontend) — gateway», «DTO Mapper (proto3 omitempty fix) — gateway», «Partial Response Fallback — gateway».

Docs Gate (Basic Auth)
GET /docs, GET /openapi.yaml — 404, пока не задан DOCS_PASSWORD.

С паролем — браузер спрашивает Basic (DOCS_USER, по умолчанию docs).

Пароль в URL не кладётся.

Swagger UI 5.17.14 лежит в репозитории (services/gateway/api/swagger/), не ходит на unpkg.

В каталоге: «Docs Gate (Basic Auth) — gateway».

Security Headers
nosniff, запрет фрейма, Referrer-Policy: no-referrer, отключение геолокации / микрофона / камеры.

ReadHeaderTimeout 5s — обрыв медленного заголовка (slowloris).

ReadTimeout/WriteTimeout не ставятся — они рвут WebSocket.

CSP на ответах: API default-src 'none', /docs — только свой хост.

HSTS — когда запрос по HTTPS или X-Forwarded-Proto: https.

В каталоге: «Security Headers — gateway».

Path Traversal Guard + Body Limit
Путь с .. или обратным слэшем — отклоняется.

Методы вне GET/HEAD/POST/PUT/PATCH/DELETE/OPTIONS — отклоняются.

Тело JSON ≤ 1 MiB. Загрузка картинок — до UPLOAD_MAX_BYTES.

В каталоге: «Path Traversal Guard — gateway», «Body Limit Middleware — gateway».

Legacy API Rewrite
/api/* → /api/v1/* (один rewrite).

Это защита от «двойного /api/api» на FE (исправлено в v1.1.0).

В каталоге: «Legacy API Rewrite — gateway».

God-function runGateway (техдолг)
runGateway — функция больше 1000 строк. Собирает все gRPC-клиенты, все routes, все middleware.

В каталоге: «Антипаттерны: Code Duplication (Hub ×2), God Function (runGateway)».

В техдолге: «Разбить на модули: bootstrap/clients.go, bootstrap/routes.go, bootstrap/middleware.go».

Необычные кейсы (стоит рассказать)
1. Circuit Breaker + Bulkhead — единственный сервис с этим.
После серии ошибок (5xx / timeout) — Open, быстрый 503. Half-Open через 10s, MaxRequests 3. Bulkhead — отдельные пулы на разные gRPC-клиенты. Если Billing тормозит — Shop не страдает. В каталоге: «Circuit Breaker + Bulkhead — единственный сервис с этим».

2. Retry Interceptor с full jitter.
На transient-ошибки (Unavailable, timeout) — retry. Full jitter: задержка = random(0, base * 2^attempt). Не фиксированная, не exponential без jitter. Размазывает retry-шторм.

3. Sliding Window Rate Limiter — fail-closed/fail-open.
Login 5/s IP — fail-closed (Redis упал → не пускает). Общий ~100/s — fail-open (Redis упал → пускает). Осознанный trade-off: брутфорс важнее не пустить, чем сохранить доступность логина. Общий лимит — наоборот, чтобы лимитер не погасил весь вход.

4. WebSocket Ticket Auth — одноразовый билет.
POST /api/v1/ws-ticket → Redis ws:ticket:{id} на 30s → {ticket}. Сокет GET /ws/leaderboard?ticket=. Билет удаляется первым GETDEL. ?token= с JWT — 401. Защита от утечки JWT через query-параметры (логи, прокси).

5. BFF + DTO Mapper + Partial Response Fallback.
Gateway — BFF: один HTTP-контракт для FE. DTO Mapper исправляет proto3 omitempty (не отличает «пустое» от «не установлено»). Partial Response Fallback — Profile отдаёт _partial: true, Gateway это проксирует.

6. Docs Gate (Basic Auth).
/docs, /openapi.yaml — 404, пока не задан DOCS_PASSWORD. С паролем — Basic Auth. Swagger UI 5.17.14 в репозитории, не ходит на unpkg. Пароль в URL не кладётся.

7. Security Headers + Path Traversal Guard + Body Limit.
nosniff, CSP, HSTS (только по HTTPS), ReadHeaderTimeout 5s (slowloris), ReadTimeout/WriteTimeout не ставятся (рвут WebSocket). .. отклоняется, JSON ≤ 1 MiB.

8. God-function runGateway (техдолг).
runGateway — больше 1000 строк. Антипаттерн: God Function. В техдолге: «Разбить на модули: bootstrap/clients.go, bootstrap/routes.go, bootstrap/middleware.go».

9. Code Duplication (Hub ×2) (техдолг).
Два Hub: app/gateway.go и websocket/hub.go. Дублирование. В техдолге: «Унифицировать».

10. Async gRPC-вызовы в admin/users без circuit breaker (техдолг).
В каталоге: «Async gRPC-вызовы в admin/users без circuit breaker. Обернуть в throughBreaker».

9. Что спросят на собесе (готовые ответы)
«Почему Gateway ×3, а не 1?»
Горизонтальный scale. Balancer :8079 распределяет least-connections. Если один Gateway упал — два других живы. JWT stateless (проверка в Auth), поэтому sticky не нужен.

«Почему Gateway зовёт Auth ValidateToken на каждом запросе, а не разбирает подпись сам?»
Auth — единственная точка правды о сессии. Gateway не разбирает подпись — зовёт Auth. Минус — лишний хоп. Плюс — нельзя обойти проверку, даже если Gateway скомпрометирован. Отзыв сессии работает мгновенно (logout → jti удалён → следующий запрос 401).

«Что такое Circuit Breaker + Bulkhead?»
После серии ошибок (5xx / timeout) — Open, быстрый 503 service temporarily unavailable. Half-Open через 10s, MaxRequests 3. Bulkhead — отдельные пулы на разные gRPC-клиенты. Если Billing тормозит — Shop не страдает. В каталоге: «единственный сервис с этим».

«Что такое Retry Interceptor с full jitter?»
На transient-ошибки (Unavailable, timeout) — retry. Full jitter: задержка = random(0, base * 2^attempt). Не фиксированная, не exponential без jitter. Размазывает retry-шторм: тысячи клиентов не бьют одновременно.

«Что такое Sliding Window Rate Limiter?»
Ключ rate:{user_or_ip}:{path}, счётчик с окном в Redis. Login 5/s IP — fail-closed (Redis упал → не пускает). Общий ~100/s — fail-open (Redis упал → пускает). Осознанный trade-off: брутфорс важнее не пустить, чем сохранить доступность логина.

«Почему login fail-closed, а общий лимит fail-open?»
Брутфорс важнее не пустить, чем сохранить доступность логина. Если Redis на лимите логина упал — пускать перестаём. Общий лимит — наоборот, чтобы лимитер не погасил весь вход при падении Redis.

«Что такое WebSocket Ticket Auth?»
POST /api/v1/ws-ticket → Redis ws:ticket:{id} на 30s → {ticket}. Сокет GET /ws/leaderboard?ticket=. Билет удаляется первым GETDEL. ?token= с JWT — 401. Защита от утечки JWT через query-параметры (логи, прокси). Origin проверяется.

«Почему билет, а не JWT в query?»
JWT в query оседает в логах прокси, в истории браузера, в Referer. Утечка. Одноразовый билет на 30s — безопаснее. Он не даёт доступа к API, только к сокету.

«Что такое BFF (Backend For Frontend)?»
Gateway — BFF: один HTTP-контракт для FE, gRPC для внутренних сервисов. FE не знает про gRPC. DTO Mapper исправляет proto3 omitempty (не отличает «пустое» от «не установлено»). Partial Response Fallback — Profile отдаёт _partial: true, Gateway проксирует.

«Что такое Docs Gate?»
/docs, /openapi.yaml — 404, пока не задан DOCS_PASSWORD. С паролем — Basic Auth. Swagger UI 5.17.14 в репозитории, не ходит на unpkg. Пароль в URL не кладётся. Это защита от публичного доступа к OpenAPI.

«Почему Security Headers + Path Traversal Guard?»
nosniff, CSP, HSTS (только по HTTPS), ReadHeaderTimeout 5s (slowloris). ReadTimeout/WriteTimeout не ставятся — рвут WebSocket. .. отклоняется, JSON ≤ 1 MiB. Это baseline security.

«Почему ReadTimeout/WriteTimeout не ставятся?»
Они рвут WebSocket-соединение. WebSocket — долгоживущее, WriteTimeout закроет его через N секунд. Вместо этого — ReadHeaderTimeout 5s для slowloris, WS живёт своей жизнью.

«Что такое gRPC → HTTP Error Mapping?»
InvalidArgument → 400, Unauthenticated → 401, PermissionDenied → 403, NotFound → 404, AlreadyExists/Aborted → 409, ResourceExhausted → 429, Unavailable → 503, Internal → 500. Gateway — единственная точка маппинга.

«Почему God-function runGateway — проблема?»
Больше 1000 строк. Собирает все gRPC-клиенты, все routes, все middleware. Антипаттерн: God Function. В техдолге: «Разбить на модули: bootstrap/clients.go, bootstrap/routes.go, bootstrap/middleware.go».

«Почему два Hub — проблема?»
app/gateway.go и websocket/hub.go — дублирование. В техдолге: «Унифицировать».

«Почему Async gRPC-вызовы в admin/users без circuit breaker — проблема?»
Если admin/users тормозит — нет fail-fast. В каталоге: «Обернуть в throughBreaker».

«Как тестируешь Gateway?»
Unit — мок gRPC-клиентов, Rate Limiter (fail-closed / fail-open), Circuit Breaker (Open → Half-Open → Closed), DTO Mapper. Integration — testcontainers (реальный Redis). k6 — browse.js (20 VU) через Balancer.
