## 🎯 Что было сделано за день

### 1. Исправление Game — персистентное сохранение рекордов
- **Проблема:** Рекорды не сохранялись в PostgreSQL, потому что в `game_repo.go` были заглушки (`// TODO`).
- **Решение:**
  - Реализованы методы `GetHighscore` и `SaveHighscore` в `game_repo.go`.
  - Добавлено подключение к PostgreSQL в `cmd/main.go`.
  - Добавлен параметр `sslmode=disable` для подключения к БД.
  - Установлен драйвер `github.com/lib/pq`.
- **Результат:** Рекорды теперь сохраняются в таблицу `highscores` в Game БД.

### 2. Восстановление Leaderboard из PostgreSQL
- **Проблема:** При перезапуске Leaderboard терял все данные, потому что хранил их только в Redis.
- **Решение:**
  - Добавлен метод `RestoreFromPostgres` в `redis_repo.go`.
  - При старте Leaderboard восстанавливает все рекорды из Game БД.
  - Добавлены поля `DBHost`, `DBPort`, `DBUser`, `DBPassword`, `DBName` в `config.go`.
  - Leaderboard теперь подключается к Game БД для восстановления.
- **Результат:** При перезапуске Leaderboard данные не теряются.

### 3. NATS кластер из 3 нод
- **Проблема:** Использовался один экземпляр NATS (single point of failure).
- **Решение:**
  - Добавлены 3 ноды NATS: `nats-1`, `nats-2`, `nats-3`.
  - Настроена кластеризация через `-cluster` и `-routes`.
  - Добавлены `server_name` и `cluster_name` для JetStream.
  - Открыты порты мониторинга: `8222`, `8223`, `8224`.
  - Обновлён `NATS_URL` во всех сервисах на кластерный URL.
- **Результат:** Отказоустойчивый NATS кластер с 3 нодами.

### 4. Обновление NATS Hub и Exporter
- **Решение:**
  - `nats-hub` теперь подключается к кластеру.
  - `nats-exporter` собирает метрики со всех 3 нод.
- **Результат:** Мониторинг NATS в Prometheus работает для всего кластера.

### 5. Исправление SSL ошибки в Billing
- **Проблема:** `pq: SSL is not enabled on the server`.
- **Решение:** Добавлен параметр `?sslmode=disable` в строку подключения к PostgreSQL.
- **Результат:** Все сервисы корректно подключаются к БД.
