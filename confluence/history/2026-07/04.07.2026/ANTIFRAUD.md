🛡️ Анти-спекулянт: Защита от мультиаккаунтинга

Сценарии злоупотребления

#	Сценарий	Как защититься
1	Создание 10 аккаунтов, фарм билетиков, выкуп всех фенек	Ограничение на количество фенек в одни руки (1 фенечка = 1 аккаунт, но 1 человек ≠ 1 аккаунт)
2	Перепродажа фенек на Avito / в VK (спекуляция)	Неизменяемый ник в момент покупки. Привязка фенечки к аккаунту.
3	Боты для автоматического фарма	Капча на вход / при достижении 10к билетиков.
4	Абуз через VPN / прокси	Ограничение по IP + Device ID (если есть).
5	Покупка аккаунтов с билетиками у других	Привязка к email / телефону. Верификация при обмене.


Конкретные меры защиты


1. Ограничение на количество фенек на аккаунт
1 фенечка в месяц на аккаунт (но 1 человек может иметь несколько аккаунтов...)

2. Привязка к реальной личности (через бусти / гугл/яндекс id)
Если пользователь хочет выкупить фенечку — он должен привязать аккаунт к бусти (где есть email / телефон).

Это сильно повышает порог входа для мультиаккаунтинга.

3. Мониторинг аномалий

```sql
    -- Запрос: пользователи, которые купили > 1 фенечку за месяц
    SELECT user_id, COUNT(*) 
    FROM purchases
    WHERE item_type = 'merch' AND date >= now() - interval '1 month'
    GROUP BY user_id HAVING COUNT(*) > 1;
```

4. Device ID + Fingerprint
Если фронтенд может отдавать fingerprint браузера — это уникальный идентификатор устройства.

Если с одного девайса играет > 3 аккаунтов в день — флаг для проверки.

5. Порог для выкупа
Фенечка стоит 20,000 билетиков.

Чтобы нафармить 20к билетиков, нужно сыграть ~200 игр (100 билетиков за игру).

Это ~10 часов гринда. Плюс капча каждые 50 игр.

🎨 Кастомизация профиля + ценообразование
Тематика: 3 эпохи
Эпоха	Стиль	Стоимость (подписка)
Средневековье	Everdale (уютная деревня)	Бесплатно (база)
Настоящее	Zenless (городской стиль)	200 руб/мес
Будущее	Звёздные войны / Вархаммер (без черепов)	300 руб/мес
Подписка 200 руб/мес — это норм!
ВкусВилл, Яндекс.Плюс, Амедиатека — всё в этом диапазоне.

Психологический порог: 200 руб — "подумать и забыть".

📊 Экономика фенечек (полка чудес)
Идея: помочь вяло продающимся авторам
Автор даёт фенечку на продажу (фото, описание, цена в билетиках).

Event Horizon выставляет в "Полку чудес".

Пользователь покупает за билетики.

Автор получает:

Рекламу его бренда (в приложении есть ссылка на автора).

% от выкупа (в реальных деньгах, если мы договоримся).

Event Horizon забирает комиссию 10-20% (билетиками или деньгами).

Почему это этично?
Нет FOMO (страха упустить): фенечки ротируются, каждая найдёт своего хозяина.

Прозрачность: пользователь видит, когда фенечка появилась и когда исчезнет.

Без спекуляции: 1 фенечка = 1 аккаунт. Если купил — она твоя навсегда.

✅ Итог: что добавить в архитектуру

```markdown
### 6. Анти-спекулянт (Anti-Fraud)

#### Меры защиты:
- [ ] Ограничение на 1 фенечку в месяц на аккаунт
- [ ] Привязка к бусти / email для выкупа фенек
- [ ] Мониторинг аномалий (покупки > 1 за месяц)
- [ ] Device ID + fingerprint (для предотвращения мультиаккаунтинга)
- [ ] Капча при достижении 10k билетиков
- [ ] Лимит на количество аккаунтов с одного IP (max 3)
```

#### Экономика:
- Фенечка: 20,000 билетиков
- Подписка: 200 руб/мес (настоящее), 300 руб/мес (будущее)
- Комиссия платформы: 10-20% от выкупа
