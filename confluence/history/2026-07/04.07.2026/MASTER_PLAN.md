## 🔥 ПРИОРИТЕТ 1 (Багфиксы)

### 1. Никнейм пользователя
- **Проблема:** смена ника у одного → меняется у всех
- **Решение:** `services/auth/internal/repository/user_repo.go` — `WHERE id = $1`

### 2. Сохранение рекорда (Flappy Bird)
- **Проблема:** нет уведомления "Счет сохранен"
- **Решение:** унифицировать для всех игр (Towers, Memory, Hexagon, Flappy)

### 3. Отображение билетиков в профиле
- **Решение:** GET `/api/billing/balance/all` → добавить в UI

### 4. Сохранение данных при перезапуске
- **Решение:** использовать `docker-compose down` (без `-v`) для сохранения volumes
