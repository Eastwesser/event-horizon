# Фронтенд инсайты — «Никуся — Блинопёк»

**Дата:** 12 мая 2026  
**Стек:** React + TypeScript + Vite  
**Цель:** Игровая платформа с гексагональным полем, drag-n-drop, WebSocket leaderboard

## Экраны (Screen Flow)

| № | Экран | Назначение |
|---|-------|------------|
| 1 | **Авторизация** | Вход/регистрация (email + пароль) |
| 2 | **Главное меню** | Выбор игры (Hexagon), кнопка «Играть», лидерборд, профиль |
| 3 | **Игровой экран** | Гексагональное поле (19 клеток), стопки блинов, поднос с 3 стопками, drag-n-drop, счёт, уровень |
| 4 | **Результат/Награда** | Очки, лампочки, билетики, новый рекорд (с множителем уровня) |
| 5 | **Лидерборд** | Топ-10 в реальном времени (WebSocket) + общий хай-скор |
| 6 | **Профиль** | Баланс лампочек/билетиков, уровень блинопекарни, история |
| 7 | **Блинопекарня** | Прокачка за лампочки, пассивный доход билетиками |
| 8 | **Экран достижений** | (Бонус) Ачивки, медали |
| 9 | **Обучение (Tutorial)** | (Бонус) Как играть |
| 10 | **Магазин скинов** | (Бонус) Скины для блинов |

## Игровая механика

### Поле
- **Размер:** 19 гексагонов (можно расширить до 21 за лампочки)
- **Тип координат:** Cube coordinates (q, r, s) или Axial (q, r)

### Поднос
- **3 стопки** с разными блинами
- Стопки: рандом, но с проверкой solvability
- Игрок перекладывает стопку на пустой гекс (drag-n-drop)

### Правила
1. Блины складываются, если два одинаковых типа рядом
2. При достижении стопки ≥10 → *пуф!* Исчезает, +очки (1 блин = 1 очко)
3. Использованы 3 стопки → поднос обновляется
4. Конец игры наступает, когда игрок не может сделать ход или сам завершает партию

### Уровни и множители

| Уровни | Сложность | Множитель | Целевые очки |
|--------|-----------|-----------|--------------|
| 1-4 | Лёгкий | x1 | 50 → 75 → 100 → 125 |
| 5-9 | Средний | x2 | 150 → 175 → 200 → 225 → 250 |
| 10-14 | Сложный | x3 | 300 → 350 → 400 → 450 → 500 |
| 15-19 | Очень сложный | x4 | 550 → 600 → 650 → 700 → 750 |
| 20 | Экстремальный | x5 | 850 |

> **Очки на уровень:** линейное увеличение +25, но множитель делает прогресс нелинейным

### Solvability
- Бэкенд должен проверять, что стопки на подносе не ведут в тупик
- Если игрок не может сделать ход → поднос обновляется или игра заканчивается

## Валюты (Billing)

| Валюта | Получение | Трата |
|--------|-----------|-------|
| **Лампочки** | Игры, ежедневные бонусы, рекорды | Открытие гексов (19→21), прокачка блинопекарни |
| **Билетики** | Пассивный доход от блинопекарни, рекорды | Скины, бусты, подсказки |

## Технические компоненты

### Клиент-серверное взаимодействие

| Действие | Метод | Эндпоинт |
|----------|-------|----------|
| Регистрация | POST | `/api/auth/register` |
| Логин | POST | `/api/auth/login` |
| Отправка рекорда | POST | `/api/game/submit` |
| Получение баланса | GET | `/api/billing/balance` |
| WebSocket лидерборд | WS | `ws://localhost:8080/ws/leaderboard` |

### Структура данных для отправки рекорда

```json
{
  "user_id": "uuid",
  "game_id": "hexagon",
  "level": 5,
  "seed": "deterministic_seed_from_game_state",
  "moves": [
    {
      "fromX": -1, "fromY": 0,   // координаты с подноса
      "toX": 0, "toY": 0,        // целевой гекс
      "timestamp": 1234567890
    }
  ]
}
Важно: Сервер сам вычисляет счёт на основе seed + moves (честная валидация). Клиент НЕ отправляет score.

Требования к UI/UX

Гексагональная сетка — с наклоном, как будто смотришь на стол
Drag-n-drop — плавное перетаскивание стопок с подноса на поле
Анимации:
Сложение стопок (блины "прыгают")
Пуф-эффект при достижении ≥10 блинов
Обновление подноса
Подсветка — валидных целевых гексов при drag-n-drop
Мобильная адаптация — позже (пока desktop)
Критерии успеха MVP

Регистрация/логин работают
Гексагональное поле отображается
Drag-n-drop с подноса на поле работает
Блины складываются при совпадении типов
Счёт обновляется при исчезновении стопки (≥10)
Поднос обновляется после 3 ходов
Рекорд отправляется в бэкенд
WebSocket показывает обновления топа
Баланс лампочек/билетиков отображается
