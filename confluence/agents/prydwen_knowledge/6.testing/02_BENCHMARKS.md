# Бенчмарки в Go

## Зачем
Найти регрессии CPU/аллокаций **до** продакшена. Не путать с нагрузкой системы (k6) — бенч меряет функцию в изоляции.

## Как писать
```go
func BenchmarkFoo(b *testing.B) {
    // setup вне цикла
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        _ = Foo()
    }
}
```
- `go test -bench=. -benchmem ./...`
- `-count=5` + `benchstat` для сравнения веток
- `b.ReportAllocs()` / смотреть `allocs/op`

## Что бенчить в EH
- JWT parse/sign (`services/auth/internal/jwt`)
- Конвертеры proto ↔ model
- Сериализация outbox payload
- TF-IDF search в `services/mcp/internal/rag` (если RAG на горячем пути)

## Антипаттерны
- Бенч с сетью/БД без `-benchtime` контроля — шум
- Оптимизация микросекунд без профиля (сначала `pprof`)
- Сравнение разных машин без нормализации

## Типичные вопросы на собесе
- Чем `b.N` отличается от фиксированного цикла?
- Как отличить аллокации от CPU-bound?
- Когда бенч бесполезен, а нужен k6/прод-метрики?
