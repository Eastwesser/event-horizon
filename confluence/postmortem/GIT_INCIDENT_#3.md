Вот правильное решение (без потерь):

Твой коммит 094fc9e5... жив на GitHub. Значит, нам не надо ничего восстанавливать из локальных dangling commit. Нам надо просто подтянуть его с удаленного сервера.

Сделай так (в корне проекта event_horizon):

bash
# 1. Убедимся, что origin/main указывает на коммит с GitHub
git fetch origin

# 2. Переставим локальный main на этот коммит (принудительно, но безопасно)
git update-ref refs/heads/main 094fc9e53fa231c1008519f1bea729400ecea64d

# 3. Починим HEAD
git symbolic-ref HEAD refs/heads/main

# 4. Проверим, что всё живо
git status
После этого git status должен ожить и показать, что ты на коммите 094fc9e5 (v1.1.3.3 docs, checkpoint). Твои изменения (если они были) никуда не денутся — они либо в этом коммите, либо в рабочей директории.
