# 🪺 NEST_RECOVERY

> *"For those who come after."*

Этот раздел — страховка для Event Horizon. 
Здесь собраны планы на случай, если гнездо (NEST) будет разрушено.

## Что внутри?
*   **DISASTER_RECOVERY.md** — Технический план: как поднять систему, если упал датацентр, сгорел сервер или нас атаковали.
*   **BUSINESS_CONTINUITY.md** — Операционный план: как выжить, если заблокировали хостинг, отозвали API или кончились деньги.
*   **COLD_START.md** — Пошаговая инструкция для «чистого листа»: как клонировать репо и восстановить данные из бэкапа за 4 часа.

## Кто это читает?
1. **Я сам** (через месяц, когда всё забуду).
2. **Любой инженер**, который придет после меня, чтобы подхватить проект.
3. **Выжившие**, которые найдут это в бэкапе через 100 лет (привет!).

## Главный принцип
Проект должен жить дольше своего создателя. 
NEST_RECOVERY — это инструкция по выживанию.
