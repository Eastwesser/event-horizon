# 🐛 Постмортем: Исправление бага с никами и статистикой

## Дата: 05.07.2026

## Проблема
1. При смене ника у одного пользователя, ник менялся у всех пользователей.
2. Статистика (рекорды, очки) была общей для всех пользователей в одном браузере.

## Причина
- Никнейм хранился в `localStorage` без привязки к `userId`.
- Статистика игр хранилась в общих ключах `gameScores`, `totalScore`.
- При загрузке профиля никнейм не синхронизировался с бэкендом.

## Решение

### Бэкенд
1. Добавлено поле `nickname` в `GetUserResponse`.
2. Добавлены поля `best_scores` и `total_score` в `GetUserResponse`.
3. Добавлен метод `GetUserScores` в `user_repo.go`.
4. Добавлен метод `GetUserScores` в `auth_service.go`.
5. Обновлён `grpc_handler.go` для возврата рекордов.

### Фронтенд
1. Все ключи `localStorage` привязаны к `userId`:
   - `gameScores_${userId}`
   - `totalScore_${userId}`
   - `gamesPlayed_${userId}`
   - `nickname_${userId}`
2. Обновлены все сторы (`flappyStore`, `gameStore`, `memoryStore`, `towerStore`).
3. В `Profile.tsx` добавлена синхронизация с бэкендом при загрузке.
4. Исправлен `handleSetNickname` — никнейм теперь обновляется через бэкенд.

## Проверка
- ✅ Смена ника влияет только на текущего пользователя.
- ✅ Статистика привязана к пользователю.
- ✅ При переключении аккаунтов данные не смешиваются.
- ✅ При загрузке профиля данные синхронизируются с бэкендом.

## Следующие шаги
- Настроить автоматическую синхронизацию статистики при каждом сохранении рекорда.
- Добавить индексы в БД для быстрого получения рекордов пользователя.
